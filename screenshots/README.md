# Screenshots

This folder contains exported PNG screenshots of all Tableau dashboards and story points.

## Naming Convention

| File | Dashboard / Story Point |
|---|---|
| `01_loan_defaulters_story.png` | Story — Loan Defaulters Analysis (all story points) |
| `02_loan_vs_income_dashboard.png` | Dashboard 1 — Loan vs Income Analysis |
| `03_defaults_vs_credit_score.png` | Dashboard 2 — Defaults vs Credit Score Analysis |

## How to Export Screenshots from Tableau

1. Open `Loan_Analysis.twbx` in Tableau Desktop
2. Navigate to the dashboard or story point you want to capture
3. Go to **Dashboard → Export Image...** (or **Story → Export Image...**)
4. Save as PNG to this `/screenshots` directory
5. Name files following the convention above
